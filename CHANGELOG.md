# Changelog

## Unreleased

- Режимы звонков VK как в Android-клиенте: «Авто API» (GUI создаёт звонки
  через `calls.start` и завершает их `calls.forceFinish` при отключении или
  падении туннеля, незавершённые — при следующем подключении) и «Авто ВК»
  (звонок создаёт bundled core 2.1.11 по VK-токену). Токен получается кнопкой
  входа VK в браузере; в поле можно вставить весь адрес `blank.html#access_token=…`.
- Отключение теперь просит ядро выйти штатно (`STOP`, в «Авто ВК» ещё
  `FINISH_VK_CALLS`) и убивает процесс только через 10 с.
- Windows: исключение `ya.ru`/`yandex.*` теперь прокладывает подсети Яндекса,
  как на Linux, а не только /32 из DNS.
- Если повторное «Подключить» отклонено при живом туннеле, кнопка больше не
  сбрасывается в «Отключено».
- При запуске GUI снимаются хвосты аварийно завершённого прошлого сеанса:
  NRPT-правило Windows (переживало перезагрузку и ломало DNS), IPv6 leak guard
  Linux, процессы ядра и незавершённые звонки «Авто API». Ошибка снятия NRPT
  при отключении теперь пишется в журнал.
- Закрытие окна при включённом VPN больше не подвешивает UI на Windows: VPN
  гасится в фоне, окно закрывается по завершении.
- DNS-сервер для исключённых доменов маршрутизируется мимо туннеля — CDN
  получают правильную геолокацию.
- Linux: bypass-маршрут, добавленный DNS-прокси в момент отключения, больше не
  остаётся после отключения.

## 2.1.15 — 2026-09-12

- На Linux скрытый переключатель автозапуска больше не отображается из-за
  `display: flex`; Linux helper для автозапуска пока не реализован.
- Linux bundle включает единую закреплённую сводку трафика и перенос текста
  из 2.1.14. Core остаётся 2.1.11; обновление сервера не требуется.

## 2.1.14 — 2026-09-12

- Сводка трафика в верхней панели использует всю ширину и переносится без обрезания.
- Единственная обновляемая сводка закреплена над историей журнала: автоскролл
  и сообщения о маршрутах больше не скрывают текущий трафик.
- Копирование журнала сохраняет актуальную сводку вместе с сообщениями и ошибками.
- Проверено на Windows с реальным VPN-трафиком, а также в браузере при ширине
  560 и 720 px. Bundled Rust core остаётся 2.1.11; обновление сервера не требуется.

## 2.1.13 — 2026-09-10

- Статистика трафика в журнале обновляется в одной строке, как на Android.
  Промежуточные сообщения и ошибки сохраняются, DOM-узел строки не пересоздаётся.
- Добавлены пять frontend-тестов, включая проверку appendLog/renderLog.
- Совместимость в настройках уточнена: наш сервер 2.1.11–2.1.13.
  Bundled Rust core остаётся 2.1.11, обновление сервера не требуется.


## 2.1.12 — 2026-09-08

- Windows updater: проверка релизов, скачивание с SHA-256/BUILDINFO, helper,
  замена bundle, перезапуск и rollback; первая установка этой версии вручную.
- Сокращены PowerShell-запуски при подключении (около 15 → 6 без повторных polls).
- Traffic counters работают без PowerShell; setup-команды отменяются вместе с Connect.
- DNS-кэш ограничен, сохраняет исходный срок TTL и не кэширует TTL=0.
- Добавлены тайминги запуска и проверка версии bundled core по SHA-256.
- Rust core и совместимый сервер остаются 2.1.11; новый Android/server не требуется.

## 2.1.11 — 2026-09-08

- DNS-прокси использует адрес, полученный в `TUNCONF`.
- Усечённые UDP DNS-ответы повторно запрашиваются по TCP.
- Ошибка Windows IPv6 guard прерывает подключение и вызывает откат маршрутов.

## 2.1.10 — 2026-08-31

- Версия Windows bundle синхронизирована с Rust core `2.1.10`.
- Protocol/runtime совместимы с server `2.1.8`; обязательного server update нет.

## 2.1.8 — 2026-08-30

- Исправлен запуск Windows VPN с серверным списком DNS `1.1.1.1,8.8.8.8`.
- `wintun.dll` перенесён рядом с GUI и проверяется до запуска transport.
- Системные route-команды сериализованы и ограничены timeout.
- Split routes активируются до DNS-proxy, поэтому публичный UDP DNS идёт внутри CSQTT.
- Исправлена CP866/UTF-8 кодировка Windows-диагностики и нативного журнала.
- Постоянные отказы пароля больше не создают бесконечные повторы.

## 2.1.7 — 2026-08-30

- удалён адрес частного сервера из defaults, README и release notes;
- endpoint собственного сервера теперь вводится пользователем явно;
- Windows и Linux bundles добавлены в единый release `csqtt-android`.

## 2.1.6 — 2026-08-30

- первый CSQTT desktop release для Windows и Linux;
- Wintun raw-IP bridge на Windows;
- нативный TUN FD transport через abstract UDS/SCM_RIGHTS на Linux;
- системные split routes, DNS proxy и IPv6 leak guard с fail-safe cleanup;
- TURN UDP и TCP/TLS, audio/video obfuscation, 9–126 workers;
- стабильный приватный device ID на установку;
- password и VK links передаются Rust transport через stdin, а не process argv;
- новый CSQTT GUI, profiles, diagnostics и session traffic metrics;
