# Проверка Linux GUI 2.1.15 — 2026-09-12

В старом работающем Linux-клиенте наблюдалось накопление строк статистики;
закреплённая сводка отсутствовала. Точный путь исполняемого файла недоступен
из-за прав root, поэтому точная версия запущенного файла не установлена.
Клиент при подготовке и выпуске обновления не останавливался и не заменялся.

Сборка основана на стабильной 2.1.14 (b6d578ef). Windows-экспериментальные
изменения обнаружения сети и bypass-маршрутов не включены.
Исправления 2.1.13/14 обеспечивают обновление одной строки статистики,
закрепление сводки над журналом и перенос длинного текста в верхней панели.
Дополнительно исправлено `.toggle[hidden]`: до правки вычисленный display был
flex при hidden=true, после — none. Это скрывает неподдерживаемый Linux-автозапуск.

Проверки браузерной части с имитацией Linux bindings: 560×460, 720×560,
960×680; после 100 обновлений сохраняется одна актуальная сводка, сообщения
остаются в истории, текст укладывается по ширине, журнал остаётся доступным.
Это Chromium-предпросмотр, а не проверка новой сборки в WebKitGTK с реальным VPN.
Такой запуск отложен для сохранения текущего соединения.

Проверки и SHA-256 релизных артефактов перечислены в BUILDINFO-2.1.15.json
и SHA256SUMS-desktop-2.1.15.txt. Bundled core 2.1.11 сверяется с core_identity.json.
Linux требует GTK 3, WebKitGTK 4.1, iproute2 и systemd-resolved.
Инструкция ручной установки — в README релизного комплекта.
